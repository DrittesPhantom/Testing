Hide or Show Inheritance Members

In this Template Inheritance members are hidden by default. To make inheritance members in the API documentation visible, remove "hideInheritance" from the List in docfx.json#L35-40

Change output directory

In this Template the standard output is publicly available at WebRoot/docs/. If you want to keep the documentation private:

  1. Change the output directory in docfx.json#L35-36 to "api":
  1. Replace the ../src/Template.UI/wwwroot/404.html with this:
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8" />
    <title>Redirecting...</title>
    <script type="text/javascript">
        var pathSegmentsToKeep = 1;
        var l = window.location;
        // Standard Blazor SPA-Routing
        l.replace(
            l.protocol + '//' + l.hostname + (l.port ? ':' + l.port : '') +
            l.pathname.split('/').slice(0, 1 + pathSegmentsToKeep).join('/') + '/?/' +
            l.pathname.slice(1).split('/').slice(pathSegmentsToKeep).join('/').replace(/&/g, '~and~') +
            (l.search ? '&' + l.search.slice(1).replace(/&/g, '~and~') : '') +
            l.hash
        );
    </script>
</head>
<body>
    <p>Redirecting to the application...</p>
</body>
</html>
