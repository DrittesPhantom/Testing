Follow this guide to get your local development environment up and running.

📋 Prerequisites

Before cloning and running the application, ensure you have the following software installed:

  • .NET 10.0 SDK (or higher)
  • An IDE or Code Editor:
    • Visual Studio 2026 (Windows-only)
    • JetBrains Rider (Cross-platform)
    • VS Code with the C# Dev Kit extension (Cross-platform)
  • A modern web browser (Edge, Chrome, Firefox)

🛠️ Local Setup Instructions

1. Clone the Repository

Open your terminal and run the following command to clone the project:

git clone https://github.com/DrittesPhantom/BlazorWebAppTemplate
cd BlazorWebAppTemplate

2. Install Workloads

Install the wasm-tools workload by running:

dotnet workload install wasm-tools --skip-manifest-update --configfile src/NuGet.Config

3. Restore Dependencies

Restore the NuGet packages using the .NET CLI:

dotnet restore

4. Run the Application

Navigate to the main project directory and start the development server:

dotnet run --project src/Template.UI/Template.UI.csproj

Once started, open your browser and navigate to https://localhost:5098 or Ctrl+Click on the link shown in the terminal.

📝 Building the Documentation Locally

If you want to preview changes made to these markdown files locally, ensure you have the DocFX CLI installed, if not run:

dotnet tool install -g docfx

Then run:

docfx docs/docfx.json --serve

Once started, open your browser and navigate to http://localhost:8080 or Ctrl+Click on the link shown in the terminal.
